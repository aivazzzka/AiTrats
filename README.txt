AiTrats (офлайн, Windows)

Запуск:
  1. Установите Python 3.9+ (если не установлен).
  2. Установите зависимость:  pip install pywebview
  3. Запустите приложение:    python app.py

Файлы:
  - app.py       — Python-скрипт, открывающий приложение в отдельном окне (pywebview).
  - index.html   — интерфейс приложения AiTrats (все стили и скрипты встроены; для Telegram Web App / Supabase CDN требуется интернет при соответствующих сценариях).

Данные (доход, категории, суммы) сохраняются автоматически в localStorage браузерного движка
окна приложения и не сбрасываются при перезапуске. Приложение не требует подключения к интернету.
