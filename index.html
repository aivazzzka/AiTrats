Облачная синхронизация (Supabase)
Supabase подключён для сохранения и синхронизации данных пользователей AiTrats по уникальному telegram_id. В Telegram используется ваш Telegram ID автоматически; в браузере на ПК введите тот же Telegram ID, чтобы данные совпадали. Данные сохраняются в таблицу user_finances.
Требуемая таблица в Supabase (SQL):
create table if not exists user_finances ( telegram_id text primary key, data jsonb not null, updated_at timestamptz default now() );
Приложение отправляет в user_finances поля telegram_id, data (актуальный JSON состояния) и updated_at. При чтении поддерживается fallback на state (если колонка есть). Для Realtime включите публикацию изменений для таблицы и настройте RLS-политику под publishable/anon-ключ в соответствии с вашей моделью доступа.
Данные и синхронизация (файл)
Экспортируйте данные в JSON для резервной копии или переноса между устройствами (ПК ↔ iPhone). Импорт заменит текущие локальные данные на содержимое файла.
